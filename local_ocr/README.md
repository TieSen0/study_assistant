# 研 Lens 本地 OCR

双击 `启动本地OCR.ps1` 即可。它会为 OCR 建立独立的 `.venv` 环境并安装依赖，不会改动 Anaconda、ComfyUI 或其他项目的 Python 包。

浏览器打开 `http://127.0.0.1:7860` 后可上传错题图片。

- **普通文字 OCR**：识别中文、英文题干和选项。
- **数学题识别**：普通文字 OCR 与 PaddleOCR 公式模型双通道运行，公式和矩阵会以 LaTeX 输出。第一次选择数学模式时，模型会下载到本机；后续识别不使用 API Token。

识别结果和标注框都留在本机。公式、矩阵、手写答案及低清图片仍必须人工对照原图复核。

首次数学识别会加载本地模型，CPU 上单张题图通常需要十余秒。整题图片先做版面分区；如果矩阵或公式漏检，可将该区域单独裁剪后用“数学题识别”上传，程序会按单个公式再次识别。
